# Photos des recettes

Dépose ici une photo par recette (PNG, JPG, WebP ou AVIF).
Le nom du fichier est l'identifiant de la recette, par exemple :

- `poulet-basquaise.png`
- `tartine-avocat-saumon-fume.webp`

Au prochain `npm run build` (ou `npm run dev`), la photo remplace automatiquement l'emoji sur le site et dans l'application.
Format conseillé : 1280 × 720 px (16/9), moins de 300 Ko.
